# Fanora · Product Facts

> 核验日期：2026-08-04
> 事实来源：仓库内产品题纲、前后端实现、合约部署文件与官方 Monad 文档。

- Fanora 是一个 AI Agent 驱动的 Web3 粉丝身份、社区贡献与记忆 NFT 共创平台。
- 演示叙事闭环为：社区贡献 → FAN 与会员成长 → AI Agent 共创 → Memory Forge → IPFS + Monad → Gallery / Collection → 社区成长。
- 当前演示网络为 Monad Testnet；官方 Monad 文档仍使用 “Monad Testnet” 名称。
- 正式会员身份由不可转让 ERC-721 SBT 承载；收藏品由 ERC-1155 承载。
- 最终 NFT 图片与 metadata 固定到 Pinata IPFS；社区与预览图使用 BeeImg 等站内存储路径。
- 产品仓库内存在可用于展示的真实 UI 截图、Fanora Logo、Monad Logo、会员与作品素材。
- 在线 Demo 地址来自题纲：`https://fanora-orpin.vercel.app/`。本次网络探测未获得有效 HTTP 响应，因此成稿中只把它作为用户提供的项目地址，不额外声称当前在线状态。
