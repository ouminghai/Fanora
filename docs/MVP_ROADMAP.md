# Fanora MVP 路线图

## 阶段 1：跑通最小闭环

1. 普通用户通过邮箱、社交账号或 Passkey 快捷登录并自动获得嵌入式钱包。
2. Web3 用户可以使用 MetaMask 或 WalletConnect 完成外部钱包签名登录。
3. 两种登录方式都创建统一 Fanora 会话，并确保账户拥有唯一主钱包。
4. 创作者创建一个签到任务。
5. 粉丝完成任务，后端验证并增加积分。
6. 达到条件后向主钱包铸造一个不可转让的 Bronze Badge。
7. Dashboard 展示积分、任务和 Badge，钱包高级信息默认隐藏。

## 阶段 2：Proof of Fandom

1. 增加任务类型和积分流水。
2. 建立 Bronze、Silver、Gold、Core 等等级。
3. LangGraph 根据行为生成活跃度、忠诚度、影响力和贡献度标签。
4. 身份升级时销毁旧等级 Badge 并铸造新等级 Badge。

## 阶段 3：轻量创作者能力

1. 粉丝列表、基础筛选和排行榜。
2. 粉丝数、任务完成率、积分和 Badge 分布等基础统计。
3. LangGraph 为粉丝生成任务推荐，并在条件满足后生成 Badge metadata 草案。
4. 创作者确认、修改或拒绝 Badge 草案后再进入发行流程。

## 暂时不做

- 多链部署。
- DAO 治理和协议代币。
- 复杂微服务架构。
- 一开始接入所有 X、Discord、Telegram 数据源。
- 把全部积分和用户数据写到链上。
- AI 运营报告、创作者聊天助手和复杂管理员工作台。
- 使用 LangGraph 处理角色、权限、任务审批或链上交易管理。
