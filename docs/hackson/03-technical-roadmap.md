# 技术路线

## 当前架构

前端：

- Next.js 应用。
- 社区、任务、排行榜、创作墙和收藏页组成主要 demo 界面。
- 通过 `NEXT_PUBLIC_API_URL` 连接后端 API。

后端：

- FastAPI 提供业务接口。
- 数据库保存用户、社区、任务、FAN 流水、会员身份和 NFT 记录。
- AI Agent 负责内容审核、粉丝画像或创作辅助能力。

链上：

- 会员身份使用 ERC-721 或相关身份合约。
- 收藏品使用 ERC-1155 或项目内已定义的收藏品合约。
- Demo 中要明确哪些操作已经上链，哪些仍是站内记录。

## 必须稳定的接口

- `GET /api/v1/community`
- `POST /api/v1/community/join`
- `GET /api/v1/tasks`
- `POST /api/v1/tasks/{task_id}/claim`
- `POST /api/v1/tasks/{task_id}/complete`
- `GET /api/v1/fan-tokens/me/ledger`
- `GET /api/v1/fan-tokens/leaderboard`
- `GET /api/v1/users/me`
- `GET /api/v1/nft/me`

## 技术风险

- 钱包、链或 RPC 不稳定。
- Demo 数据不足，导致页面空态过多。
- AI 接口超时或密钥缺失。
- 图片资源加载慢。
- 移动端或投屏比例下 UI 挤压。

## 备用方案

- 保留一套可直接演示的种子数据。
- 对链上操作准备截图或已确认交易链接。
- 对 AI 操作准备降级文案，说明规则审核如何工作。
- 对网络问题准备本地运行路径。
