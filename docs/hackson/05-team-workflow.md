# 团队协作

## 分工建议

产品与叙事：

- 维护目标、用户旅程和演示脚本。
- 保证每个功能都能服务黑客松故事。

前端：

- 保证主页面视觉统一。
- 打磨 demo 交互、加载状态和错误提示。
- 准备投屏比例下的展示效果。

后端：

- 保证核心 API 稳定。
- 准备演示数据和降级路径。
- 记录接口、环境变量和部署方式。

合约与链上：

- 确认合约部署状态。
- 准备交易哈希、合约地址和浏览器链接。
- 明确 demo 中链上操作的真实边界。

AI Agent：

- 确认审核、画像或推荐能力可以稳定展示。
- 准备接口失败时的降级逻辑和解释。

## 每日节奏

上午：

- 确认当天必须完成的 3 件事。
- 更新阻塞问题。

下午：

- 集中开发和联调。
- 至少跑一次核心 demo 路径。

晚上：

- 修 demo 路径里的明显问题。
- 更新文档、截图和明日计划。
