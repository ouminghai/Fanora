# 演示脚本

## 30 秒开场

Fanora 是一个 AI Agent 驱动的 Web3 粉丝身份与互动协议。它帮助创作者把粉丝的真实参与记录下来，形成 FAN、等级、排行榜、链上会员身份和数字收藏品。

传统平台里，创作者很难知道谁是真正长期参与的人；Fanora 把任务、互动、审核和奖励连成一个闭环，让粉丝贡献可以被看见、验证和激励。

## 3 分钟演示路线

1. 打开首页，说明 Fanora 的核心定位。
2. 进入 Community，展示官方社区和成员数据。
3. 展示签到或任务模块，说明真实互动如何获得 FAN。
4. 进入任务中心，领取一个任务。
5. 完成任务或展示已完成状态，说明 AI 审核与自动发奖。
6. 打开 Fan Token 排行榜，展示前 10 名粉丝。
7. 进入个人收藏或会员身份页，展示链上身份和 NFT 收藏品。
8. 总结创作者如何用这些数据识别核心粉丝。

## 5 分钟扩展讲法

可以补充：

- FAN 是站内可审计贡献单位，不强调投机。
- 会员身份记录长期等级，升级时身份保持连续。
- AI Agent 参与内容质量判断，减少刷任务和垃圾内容。
- NFT 收藏品代表活动纪念和贡献证明。
- 排行榜用于运营识别和激励设计。

## 关键页面讲解词

Community：

这里是 Fanora 官方社区，粉丝可以签到、参与任务、发布创作，并把这些行为转化为可见贡献。

Tasks：

任务不是简单点击领奖，而是要求用户完成真实互动。系统会记录参与状态，并在验证后发放 FAN。

Leaderboard：

排行榜展示当前 FAN 排名前 10 的公开用户，创作者可以快速识别高价值粉丝，粉丝也能看到自己的成长位置。

Collection：

这里展示用户的会员身份和收藏品。它们把粉丝贡献从普通平台数据，沉淀为更长期、更可携带的身份资产。

## 结束语

Fanora 的核心价值是把粉丝关系从平台里的零散互动，升级成可验证、可运营、可奖励的链上身份网络。
