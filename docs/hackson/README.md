# Fanora 黑客松推进文档

这个文件夹用于集中管理 Fanora 参加黑客松期间的目标、计划、开发过程、演示准备和提交材料。所有文件都尽量保持短、清晰、可执行，方便团队每天更新。

## 推荐阅读顺序

1. [目标描述](./00-goals.md)：明确这次黑客松要证明什么、交付什么、不做什么。
2. [推进计划](./01-hackathon-plan.md)：按阶段安排每天要完成的事项。
3. [产品范围](./02-product-scope.md)：锁定 demo 里的用户旅程和功能边界。
4. [技术路线](./03-technical-roadmap.md)：记录架构、接口、链上能力和验收标准。
5. [演示脚本](./04-demo-script.md)：准备评委能快速理解的演示节奏。
6. [团队协作](./05-team-workflow.md)：分工、会议节奏、决策和风险同步。
7. [反馈记录](./06-feedback-log.md)：收集团队、用户、导师和评委反馈。
8. [提交清单](./07-submission-checklist.md)：最终提交前逐项确认。

## 当前一句话目标

Fanora 要在黑客松中展示一个由 AI Agent 驱动的 Web3 粉丝身份与互动协议：粉丝通过真实社区行为获得 FAN，沉淀公开身份、等级和收藏品，创作者可以识别并奖励高价值粉丝。

## 每日推进方式

- 每天开始前更新 `01-hackathon-plan.md` 的今日目标。
- 每完成一个关键功能，在 `03-technical-roadmap.md` 更新状态。
- 每次用户测试或导师沟通后，在 `06-feedback-log.md` 记录反馈和下一步动作。
- 演示前至少按 `04-demo-script.md` 完整走查 3 次。
- 提交前只看 `07-submission-checklist.md`，避免遗漏。
