# 产品范围

## Demo 主用户旅程

1. 用户打开 Fanora。
2. 用户连接钱包或登录。
3. 用户加入 Fanora 官方社区。
4. 用户进入任务中心，领取并完成一个真实互动任务。
5. 系统发放 FAN，并更新个人成长状态。
6. 用户查看 Fan Token 排行榜，理解自己和核心粉丝的位置。
7. 用户进入个人收藏或会员身份页面，看到链上身份和数字收藏品。

## 核心页面

- 首页：传达 Fanora 是什么，并引导进入社区和任务。
- Community：社区中心，包含签到、任务、创作和排行榜入口。
- Community Tasks：任务中心，展示可领取任务。
- Community Leaderboard：Fan Token 排名前 10 的公开用户。
- Creation Wall：社区创作内容。
- Profile 或 Collection：用户成长、会员身份和收藏品。

## 必须清楚表达的产品概念

- FAN：站内可审计的粉丝贡献单位。
- 会员身份：承载粉丝等级和长期身份的链上凭证。
- 任务：把真实互动变成可验证贡献。
- AI Agent：辅助审核、画像和推荐，降低运营成本。
- 排行榜：帮助创作者识别高价值粉丝，也给粉丝即时反馈。

## MVP 边界

本次只做单一官方社区，不扩展多社区平台能力。

本次强调粉丝贡献和身份，不强调 Token 投机、交易和价格。

本次让链上身份和收藏品服务于证明与纪念，不做复杂金融系统。

## Demo 数据要求

- 至少 10 个公开用户用于排行榜展示。
- 至少 3 个任务，覆盖签到、回复或活动页互动。
- 至少 3 条社区创作内容。
- 至少 1 个用户有较完整的 FAN、等级、身份和收藏品数据。
