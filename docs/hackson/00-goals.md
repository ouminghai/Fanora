# 目标描述

## 黑客松总目标

在有限时间内，把 Fanora 打磨成一个可以被评委快速理解、可以稳定演示、可以体现 Web3 和 AI Agent 价值的产品 demo。

核心不是堆功能，而是证明一个闭环：

1. 粉丝进入 Fanora 官方社区。
2. 粉丝完成真实互动任务，获得 FAN。
3. FAN 形成可见的成长、等级和排行榜。
4. 正式会员可以拥有链上身份与收藏品。
5. 创作者可以用这些数据识别核心粉丝，并设计下一轮激励。

## 成功标准

- 评委在 3 分钟内理解 Fanora 解决的问题。
- Demo 能展示从登录、加入社区、任务、FAN、排行榜到身份收藏的核心路径。
- AI Agent 的作用被明确看见：不是装饰，而是参与审核、画像或创作辅助。
- 链上部分有清楚边界：哪些已经真实上链，哪些是站内可审计积分。
- 项目材料完整：README、演示脚本、提交说明、部署链接、合约或架构说明。

## 用户目标

粉丝希望：

- 用简单方式证明自己是真实参与者。
- 看到自己的贡献被记录、排名和奖励。
- 获得有纪念意义的数字身份或收藏品。

创作者希望：

- 找到真正愿意互动、共创和支持的核心粉丝。
- 用任务、FAN 和收藏品建立长期运营机制。
- 降低活动审核、粉丝分层和奖励发放的成本。

## 本次黑客松必须交付

- 可访问的前端 demo。
- 可用的社区任务中心。
- FAN 余额、流水或排行榜展示。
- 至少一条可演示的粉丝任务路径。
- 会员身份或 NFT 收藏品展示。
- 清晰的项目介绍和技术说明。
- 最终演示脚本。

## 本次黑客松暂不追求

- 完整商业化后台。
- 多创作者、多社区复杂权限。
- 大规模真实用户运营。
- 完整链上 Token 经济。
- 过度复杂的二级市场和金融化叙事。

## 评委应该记住的一句话

Fanora 把粉丝的真实参与变成可验证的身份、贡献和奖励，让创作者拥有一个由 AI 辅助运营的链上粉丝关系层。
